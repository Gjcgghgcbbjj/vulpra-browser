## 一、项目目标

Vulpra 是 iOS Gecko 内核移植浏览器（Firefox 152 引擎 + Swift 原生前端，TrollStore 侧载分发）。本轮工作的总目标：**在真机上达到日常可用**——崩溃清零、谷歌认证通过、界面优雅、交互顺手。

## 四、核心技术决策记录

1. **谷歌认证 = 身份一致性**：伪装 iOS Safari 失败（TLS/头序交叉验证穿帮）；声明 Android Firefox 152 成功——因为引擎就是 Firefox 152，所有可检验层自洽。引擎级 `general.useragent.override` 经运行时 SetPref 通道注入。
2. **沉浸式 = 不加浮层**：三代退出按钮全部失败的教训是"任何常驻控件都违背沉浸"。最终方案消费引擎原生 `GeckoView:ScrollChanged` 遥测（需在窗口初始化 modules 字典启用 `GeckoViewScroll`——这是曾导致事件不通的隐藏前提）。
3. **设置解码必须容错**：合成 Codable 在旧文件缺新键时整体丢弃重置（静默吞掉用户偏好）。改为逐字段 `decodeIfPresent` + schemaVersion 迁移机制。
4. **监听器注册幂等性**：EventDispatcher.addListener 无条件追加；跨会话复用的观察者必须自带身份去重。
5. **导航入口集中**：Chrome 模式把书签/历史/下载/设置放 ··· 菜单顶部，起始页只保留搜索与快捷方式。

## 六、已知边界与后续建议

1. **120Hz 微卡**：应用侧已无节流；下一步需引擎 WebRender 光栅化调参（substrate 级改动，约 3h 构建）。
2. **快捷方式上限 8 个**：可扩展长按磁贴的移除/固定管理。
3. **BrowserViewController 体量大**（~480 行）：滚动/手势/隐私遮罩可拆分为子控制器。
4. **诊断基建**：EngineDiagnostics（设置内自检）与 VULPRA_DIAG 日志体系保留，后续问题可快速定位。
